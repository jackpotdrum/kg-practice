# ナップサックDP

## 概要

容量・予算などの制約内で、価値を最大化するDP。

- `dp[w]`: 重さ（容量）`w` までで達成できる最大価値
- 0/1 か 無制限かでループ方向が変わる

## 1. どんな問題で使うか

- 各アイテムに重さと価値がある
- 制約以内で最大価値（または最小コスト）を求める
- 「選ぶ/選ばない」の組合せ最適化

典型例:

- 0/1ナップサック
- 個数無制限ナップサック
- 部分和判定（価値を bool に置換）

## 2. 0/1 と無制限の違い

- 0/1: 各アイテムは1回まで
  - `w` を大きい方から小さい方へ回す
- 無制限: 同一アイテムを何回でも使える
  - `w` を小さい方から大きい方へ回す

## 3. 実装テンプレ（0/1）

```python
def knapsack_01(items, W):
    # items: [(weight, value), ...]
    dp = [0] * (W + 1)

    for weight, value in items:
        for w in range(W, weight - 1, -1):
            dp[w] = max(dp[w], dp[w - weight] + value)

    return dp[W]
```

## 4. 計算量

- 時間: O(NW)
- 空間: O(W)

## 5. よくあるミス

- 0/1 なのに `w` を昇順で回して多重使用してしまう
- `dp[w]` の意味（ちょうどwか、w以下か）を曖昧にする
- 制約が大きすぎるのに O(NW) を選ぶ
