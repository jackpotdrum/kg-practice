# 動的計画法（DP）リファレンス

## 使い分け早見表

- 線形に1ステップずつ決める: `線形DP.md`
- 区間 `[l, r]` を縮めながら最適化: `区間DP.md`
- 容量や予算内で価値最大化: `ナップサックDP.md`
- 文字列同士の一致/編集: `文字列DP.md`
- マス目移動や経路数: `グリッドDP.md`
- 木構造上で部分木ごと集約: `木DP.md`
- 部分集合を状態として管理: `集合DP_bitDP.md`
- モード/状態遷移を管理: `状態機械DP.md`

## DPで共通して最初に決める3点

1. 状態（何を覚えるか）
2. 遷移（どこから来るか）
3. 初期値と答えの取り方

この3点を先に日本語で書いてから実装すると崩れにくい。
