## 問題文
あなたは動画配信サービスの運用チームに所属しており、障害分析のために時系列イベントログを調査しています。
監視システムからは、1分ごとに「イベント種別ID」が1件ずつ記録されます。運用上、特定のイベント種別が一定回数以上そろって初めて「再現性のある障害パターン」と判断できます。

現在、障害判定ルールとして「種別2は2回以上、種別4は1回以上、種別5は1回以上」のような必要条件が定義されています。
あなたのタスクは、これらの必要条件をすべて満たす連続区間のうち、最も短い区間を特定することです。区間が短いほど、原因追跡の工数が下がるため、運用判断に直結します。

ただし、監視ログは最大20万件に達するため、単純な全探索では制限時間内に終わりません。
正確性を保ちつつ、計算量を意識した実装を行ってください。

## 入出力仕様 / 制約
### 入力仕様

- 1行目に整数 N, M が与えられる。
- 2行目に長さ N の整数列 A_1, A_2, ..., A_N が与えられる。
- 続く M 行のうち、i 行目に整数 T_i, C_i が与えられる。
- これは「イベント種別 T_i が区間内に少なくとも C_i 回必要」であることを表す。

### 出力仕様

- 条件を満たす連続区間が存在する場合、以下を空白区切りで出力する。
- l r (r-l+1)
- ここで l, r は1-indexedの区間両端。
- 条件を満たす区間が複数ある場合は、次の優先順で1つに決める。
  - 区間長が最小
  - 区間長が同じなら l が最小
  - それでも同じなら r が最小
- 存在しない場合は -1 を出力する。

### 制約

- 1 <= N <= 2 * 10^5
- 1 <= M <= 2 * 10^5
- 1 <= A_i <= 10^9
- 1 <= T_i <= 10^9
- 1 <= C_i <= N
- 同じ T_i は入力内で重複しない。
- 想定計算量: O(N) または O(N log N) 程度

### 注意事項

- 必要条件に含まれない種別IDは、区間内に何回含まれていてもよい。
- 必要条件に含まれる種別IDがログ全体に十分存在しない場合は -1。
- 区間は必ず連続でなければならない（部分列は不可）。

### サンプル入力

```text
12 3
4 2 7 2 5 7 2 4 5 7 4 2
2 2
4 1
5 1
```

### サンプル出力

```text
1 5 5
```

### サンプル説明

- 区間 [1,5] = [4,2,7,2,5] には次が含まれる。
  - 種別2が2回
  - 種別4が1回
  - 種別5が1回
- 長さ4以下で条件を満たす区間は存在しないため、最短長は5。
- 長さ5の候補が他にもあっても、開始位置 l が最小の [1,5] を採用する。

import argparse
import copy


class Validator:
    def __init__(self, length, events, types):
        self.length = length
        self.events = events
        self.types = types
        self.errors = []
        self.valid_flag = True

    def valid_length(self):
        if not (1 <= self.length[0] <= 2 * 10 ** 5):
            self.errors.append("イベント数は1以上2*10^5以下で指定してください。")
            self.valid_flag = False

        if not (1 <= self.length[1] <= 2 * 10 ** 5):
            self.errors.append("イベント種別の数は1以上2*10^5以下で指定してください。")
            self.valid_flag = False

        return

    def valid_events(self):
        if not (1 <= len(self.events) <= 10 ** 9):
            self.errors.append("イベント数は1以上10^9以下で指定してください。")
            self.valid_flag = False
            return

    def valid_types(self):
        if len(self.types) % 2 != 0:
            self.errors.append("イベント種別と障害判定数はペアで指定してください。")
            self.valid_flag = False
            return

        event_types = self.types[0::2]
        has_dup = len(event_types) != len(set(event_types))
        if has_dup:
            self.errors.append("イベント種別は重複しないように指定してください。")
            self.valid_flag = False
            return

        event_falg = False
        failure_flag = False
        for i in range(0, len(self.types), 2):
            event_type = self.types[i]
            failure_count = self.types[i + 1]
            if not (1 <= event_type <= 10 ** 9):
                event_falg = True
            if not (1 <= failure_count <= self.length[0]):
                failure_flag = True

        if event_falg:
            self.errors.append("イベント種別は1以上10^9以下で指定してください。")
            self.valid_flag = False
        if failure_flag:
            self.errors.append("障害判定数は1以上区間長以下で指定してください。")
            self.valid_flag = False

        return

    def validate(self):
        self.valid_length()
        self.valid_events()
        self.valid_types()
        return self.valid_flag, self.errors


class EventSectionManager:
    def __init__(self, length, events, types):
        events_length = length[0]
        failure_length = length[1]
        in_range_events = events[:events_length]
        event_types = []
        secondary_structure_types = []
        for i in range(0, len(types), 2):
            event_type = types[i]
            failure_count = types[i + 1]
            event_types.append(event_type)
            secondary_structure_types.append([event_type, failure_count])

        self.events_length = events_length
        self.failure_length = failure_length
        self.events = in_range_events
        self.event_types = event_types
        self.types = secondary_structure_types
        self.calculator = EventSectionCalculator()
        self.insufficient_val = -1

    def get_sections(self):
        sections = []
        for i in range(self.events_length):
            section = self.calculator.get_section_length(
                self.events, copy.deepcopy(self.types), i, self.event_types)
            if section:
                sections.append(section)

        return sections

    def get_section(self):
        sections = self.get_sections()
        if not sections:
            return self.insufficient_val

        shortest_section = self.calculator.get_shortest_section(sections)
        return shortest_section


class EventSectionCalculator:
    def __init__(self):
        pass

    def is_count_all_zero(self, types):
        for _, failure_count in types:
            if failure_count > 0:
                return False
        return True

    def decrement_counts(self, types, event):
        for type in types:
            if type[0] == event:
                type[1] -= 1
                break

    def get_section_length(self, events, types, start_event, event_types):
        if events[start_event] not in event_types:
            return []

        section = [start_event]
        for i in range(start_event, len(events)):
            if events[i] in event_types:
                self.decrement_counts(types, events[i])
                if self.is_count_all_zero(types):
                    section.append(i)
                    return section
        return []

    def get_shortest_section(self, sections):
        min_len = min(sections, key=len)
        all_shortest = [x for x in sections if len(x) == len(min_len)]

        row = min(all_shortest, key=lambda r: r[0])

        return row

    parser = argparse.ArgumentParser(description="最短障害発生区間を求める")
    parser.add_argument("--length", type=int, nargs=2)
    parser.add_argument("--events", type=int, nargs="+")
    parser.add_argument("--types", type=int, nargs="+")
    return parser.parse_args()

            print(error)

    if shortest_section == manager.insufficient_val:
        print(shortest_section)
    else:
        section_val = " ".join(map(str, shortest_section))
        print(section_val)

    return

if __name__ == "__main__":
    main()

## 模範解答
```python
import argparse
from collections import defaultdict


def parse_args():
    parser = argparse.ArgumentParser(description="最短障害発生区間を求める")
    parser.add_argument("--length", type=int, nargs=2, required=True)
    parser.add_argument("--events", type=int, nargs="+", required=True)
    parser.add_argument("--types", type=int, nargs="+", required=True)
    return parser.parse_args()


def validate_input(n, m, events, raw_types):
    errors = []

    if not (1 <= n <= 2 * 10**5):
        errors.append("N は 1 以上 2*10^5 以下で指定してください。")
    if not (1 <= m <= 2 * 10**5):
        errors.append("M は 1 以上 2*10^5 以下で指定してください。")

    if len(events) != n:
        errors.append("events の要素数は N と一致させてください。")
    if len(raw_types) != 2 * m:
        errors.append("types の要素数は 2*M（T_i, C_i のペア）にしてください。")

    for x in events:
        if not (1 <= x <= 10**9):
            errors.append("events の各値は 1 以上 10^9 以下で指定してください。")
            break

    return errors


def build_required_counts(raw_types, n):
    required_counts = {}

    for i in range(0, len(raw_types), 2):
        event_type = raw_types[i]
        required_count = raw_types[i + 1]

        if event_type in required_counts:
            raise ValueError("イベント種別は重複しないように指定してください。")
        if not (1 <= event_type <= 10**9):
            raise ValueError("イベント種別は 1 以上 10^9 以下で指定してください。")
        if not (1 <= required_count <= n):
            raise ValueError("必要回数は 1 以上 N 以下で指定してください。")

        required_counts[event_type] = required_count

    return required_counts


def solve_shortest_window(events, required_counts):
    total_counts = defaultdict(int)
    for event in events:
        if event in required_counts:
            total_counts[event] += 1

    for event_type, required_count in required_counts.items():
        if total_counts[event_type] < required_count:
            return -1

    target_type_count = len(required_counts)
    satisfied_type_count = 0
    window_counts = defaultdict(int)

    best_window = None  # (window_len, left, right) 0-indexed
    left = 0

    for right, event in enumerate(events):
        if event in required_counts:
            window_counts[event] += 1
            if window_counts[event] == required_counts[event]:
                satisfied_type_count += 1

        # 全条件を満たしている間は左端を詰めて最短化する
        while satisfied_type_count == target_type_count and left <= right:
            current_window = (right - left + 1, left, right)
            if best_window is None or current_window < best_window:
                best_window = current_window

            left_event = events[left]
            if left_event in required_counts:
                if window_counts[left_event] == required_counts[left_event]:
                    satisfied_type_count -= 1
                window_counts[left_event] -= 1
            left += 1

    if best_window is None:
        return -1

    window_len, left_idx, right_idx = best_window
    return left_idx + 1, right_idx + 1, window_len


def main():
    args = parse_args()
    n, m = args.length
    events = args.events[:n]
    raw_types = args.types

    errors = validate_input(n, m, events, raw_types)
    if errors:
        print("入力に誤りがあります。以下を確認してください。")
        print("======================================")
        for error in errors:
            print(error)
        return

    try:
        required_counts = build_required_counts(raw_types, n)
    except ValueError as err:
        print("入力に誤りがあります。以下を確認してください。")
        print("======================================")
        print(str(err))
        return

    ans = solve_shortest_window(events, required_counts)
    if ans == -1:
        print(-1)
    else:
        print(ans[0], ans[1], ans[2])


if __name__ == "__main__":
    main()
```

## 解説
今回の本質は「条件を満たす最短連続区間」なので、全探索ではなくスライディングウィンドウが適している。
右端を伸ばしつつ必要条件を満たしたら左端を縮めることで、各要素を高々定数回しか処理せず O(N) で解ける。
最短判定は (区間長, l, r) のタプル比較で実装するとタイブレークを自然に満たせる。

## 計算量メモ
- あなたの解答: 最悪で O(N^2) 相当 + deepcopy コスト
- 模範解答: 時間 O(N), 空間 O(K)（K は必要種別数）

## 学びの要点（再発防止チェックリスト）
- 出力形式は実装前に固定し、最後にサンプル照合する
- 最短判定キーは (区間長, l, r) の順で明示する
- 制約が大きいときは first choice で two pointers を検討する
- 不成立ケースは事前カウントで早期判定する

## 間違えた原因（自己分析）
- section を [start, end] で持ちながら len(section) を区間長比較に使ってしまった
- 最短区間問題で sliding window へ早く切り替えられなかった
- 1-indexed の出力仕様確認が不足した
