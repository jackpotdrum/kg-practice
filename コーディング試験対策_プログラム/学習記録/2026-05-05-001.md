### 出題原文（省略なし）
1. タイトル
プログラミング模擬試験 #003（Medium〜Hard）

2. 問題文
あなたはサブスクリプションサービスの運用チームで、日次の通知配信戦略を最適化する担当です。
各日について、戦略A（新規獲得重視）と戦略B（解約抑止重視）の2案があり、どちらを採用するかでその日の期待利益が変わります。過去実績から、各日の「Aを選んだ場合の利益」「Bを選んだ場合の利益」は見積もられています。

ただし、戦略を切り替えるたびに現場オペレーションに調整負荷がかかるため、月内の切り替え回数には上限があります。
切り替えを増やせば利益が上がるとは限らず、逆に切り替えが多すぎると現場混乱で意思決定が遅れ、施策実行が失敗するリスクが高まります。

あなたの仕事は、N日間で戦略A/Bを1つずつ選び、切り替え回数をK回以下に抑えながら、総利益を最大化することです。
本番環境ではデータ件数が大きいため、正確性に加えて計算量を意識した実装が必要です。

3. 入力仕様
- 1行目: 整数 N, K
- 2行目: 長さNの整数列 A_1, A_2, ..., A_N
    - A_i は i日目に戦略Aを選んだときの利益
- 3行目: 長さNの整数列 B_1, B_2, ..., B_N
    - B_i は i日目に戦略Bを選んだときの利益

4. 出力仕様
- 切り替え回数が K 以下となるように戦略を選んだときの、達成可能な総利益の最大値を1つ出力せよ。

5. 制約
- 1 <= N <= 2 * 10^5
- 0 <= K <= min(N-1, 50)
- -10^9 <= A_i, B_i <= 10^9
- 切り替え回数は「前日と異なる戦略を選んだ日数」で数える。
- 想定計算量: O(NK)
- 想定追加メモリ: O(K) から O(NK)（実装方針による）

6. 注意事項
- 1日目は前日がないため、切り替え回数は増えない。
- 利益は負値を取りうる（損失日がある）。
- K=0 の場合、全日同じ戦略しか選べない。
- N=1 の場合、切り替えは常に0回。
- 64bit整数で扱うこと（Pythonのintなら可）。

7. サンプル入力
```text
6 2
8 3 7 -2 6 4
5 9 1 10 2 8
```

8. サンプル出力
```text
48
```

9. サンプル説明
- 例えば以下の選択が最適の一つ:
    - 日1: A(8)
    - 日2: B(9)  ← 1回目の切り替え
    - 日3: A(7)  ← 2回目の切り替え
    - 日4: A(-2)
    - 日5: A(6)
    - 日6: A(4)
- 総利益は 8 + 9 + 7 - 2 + 6 + 4 = 32 では最大にならない。
- より良い選択として、
    - 日1: B(5), 日2: B(9), 日3: B(1), 日4: B(10), 日5: A(6), 日6: A(4)
    - 切り替え1回、総利益35
- さらに最適化すると、切り替え2回以内で最大利益 48 を達成できる。
    （実装で厳密に探索して求めること）

10. 受講者が誤解しやすいポイント
- 「高い方を日ごとに貪欲選択」だと切り替え上限を超えたり、全体最適を逃す。
- 切り替え回数は日数ではなく「前日との差分回数」。
- Kが小さいため、状態設計を「日付 × 切り替え回数 × 最終戦略」で持つDPが有効。

import argparse

def validate_input(length, count, plan_a, plan_b):
    errors = []

    if not (1 <= length <= 2 * 10 ** 5):
        errors.append("データ件数は1以上2×10^5以下でなければなりません。")
    if not (0 <= count <= min(length - 1, 50)):
        errors.append("戦略A/Bの切り替え回数は0以上かつ\
                      データ件数-1もしくは50以下でなければなりません。")
    if not (length == len(plan_a) == len(plan_b)):
        errors.append("データ件数と戦略A/Bの利益の数は一致していなければなりません。")
    for a in plan_a:
        if not (-10 ** 9 <= a <= 10 ** 9):
            errors.append("戦略Aの利益は-10^9以上10^9以下でなければなりません。")
            break
    for b in plan_b:
        if not (-10 ** 9 <= b <= 10 ** 9):
            errors.append("戦略Bの利益は-10^9以上10^9以下でなければなりません。")
            break
    
    return errors

def parse_args():
    parser = argparse.ArgumentParser(description="戦略A/BをK回以下に抑え総利益の最大値を求める")
    parser.add_argument("--length_count", type=int, nargs=2)
    parser.add_argument("--plan_a", type=int, nargs="*")
    parser.add_argument("--plan_b", type=int, nargs="*")
    return parser.parse_args()

def gross_profit(length, count, plan_a, plan_b):
    # 切り替え無しの利益を計算
    profit_a = sum(plan_a)
    profit_b = sum(plan_b)
    no_change_profit = [profit_a, profit_b]

    if length == 1 or count == 0:
        return max(no_change_profit)
    
    # 切り替え回数が1以上の場合の利益を計算
    negative_inf = -10 ** 30

    # prev_a[c]: 前日まで見て「最後がA」で切り替え回数が c 回の最大利益
    # prev_b[c]: 前日まで見て「最後がB」で切り替え回数が c 回の最大利益
    prev_a = [negative_inf] * (count + 1)
    prev_b = [negative_inf] * (count + 1)

    # 1日目は切り替え回数0でAかBを選ぶだけ
    prev_a[0] = plan_a[0]
    prev_b[0] = plan_b[0]

    for day in range(1, length):
        cur_a = [negative_inf] * (count + 1)
        cur_b = [negative_inf] * (count + 1)

        for changes in range(count + 1):
            # 前日もAを選んで今日もA（切り替え回数は増えない）
            cur_a[changes] = prev_a[changes] + plan_a[day]
            # 前日もBを選んで今日もB（切り替え回数は増えない）
            cur_b[changes] = prev_b[changes] + plan_b[day]

            if changes > 0:
                # B -> A に切り替える
                cur_a[changes] = max(cur_a[changes], prev_b[changes - 1] + plan_a[day])
                # A -> B に切り替える
                cur_b[changes] = max(cur_b[changes], prev_a[changes - 1] + plan_b[day])

        prev_a = cur_a
        prev_b = cur_b

    return max(max(prev_a), max(prev_b))


def main():
    args = parse_args()
    length, count = args.length_count
    plan_a = args.plan_a
    plan_b = args.plan_b

    errors = validate_input(length, count, plan_a, plan_b)
    if errors:
        print("入力に誤りがあります")
        print("======================================")
        for error in errors:
            print(error)
        return
    
    result = gross_profit(length, count, plan_a, plan_b)
    print(result)

    return

if __name__ == "__main__":
    main()

## 模範解答
```python
from typing import List


def gross_profit(length: int, count: int, plan_a: List[int], plan_b: List[int]) -> int:
    if length == 1 or count == 0:
        return max(sum(plan_a), sum(plan_b))

    negative_inf = -10 ** 30
    prev_a = [negative_inf] * (count + 1)
    prev_b = [negative_inf] * (count + 1)

    prev_a[0] = plan_a[0]
    prev_b[0] = plan_b[0]

    for day in range(1, length):
        cur_a = [negative_inf] * (count + 1)
        cur_b = [negative_inf] * (count + 1)

        for changes in range(count + 1):
            # 継続
            cur_a[changes] = prev_a[changes] + plan_a[day]
            cur_b[changes] = prev_b[changes] + plan_b[day]

            # 切替
            if changes > 0:
                cur_a[changes] = max(cur_a[changes], prev_b[changes - 1] + plan_a[day])
                cur_b[changes] = max(cur_b[changes], prev_a[changes - 1] + plan_b[day])

        prev_a = cur_a
        prev_b = cur_b

    return max(max(prev_a), max(prev_b))
```

## 解説
- `prev_a[c]`: 前日までで「最後がA」かつ「切り替え回数 c 回」の最大利益。
- `prev_b[c]`: 前日までで「最後がB」かつ「切り替え回数 c 回」の最大利益。
- 遷移
  - 継続: A->A / B->B は `c` を維持。
  - 切替: B->A / A->B は `c-1` から `c` に遷移。
- 同じ状態に複数ルートが来るので、`max` で最良値のみ保持する。
- 最終的に `0..K` の全状態から最大値を取る。

## 計算量メモ
- 時間計算量: O(NK)
- 空間計算量: O(K)
- N <= 2 * 10^5, K <= 50 なので実用範囲。

## 学びの要点（再発防止チェックリスト）
- 状態は「未来の選択に必要な情報だけ」で設計する。
- 配列 index の意味（ここでは切り替え回数）を固定して読む。
- 継続遷移と切替遷移を分けて実装する。
- `changes > 0` を忘れずに境界を守る。
- 比較不要な更新は代入にして可読性を上げる。
